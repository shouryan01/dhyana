# Keyboard shortcuts

`Mod` is <kbd>Ctrl</kbd> on Windows and <kbd>⌘</kbd> on macOS. Chords work everywhere. Single keys and sequences (like <kbd>G</kbd> <kbd>T</kbd>) only work when you're **not** typing in the editor; press <kbd>Esc</kbd> to leave it.

| Action | Shortcut |
|---|---|
| Open command palette | `Mod K` |
| Go to today | `G T` or `Mod Shift T` |
| Previous / next day | `Mod [` / `Mod ]` (or `[` / `]` outside the editor) |
| Go to date… | `Mod G` or `G D` |
| Focus editor | `I` |
| Toggle sidebar | `Mod \` |
| Open settings | `Mod ,` or `G S` |
| Show keyboard shortcuts | `?` |
| Replay onboarding | palette only |
| Theme: Paper / Light / Dark | palette only |

"Go to date" understands `2026-10-28`, `yesterday`, `tomorrow`, `-3`, `friday`, `next monday`, `last friday`.

The same list is shown in **Settings → Keyboard shortcuts**, generated from the app's action registry. Remapping arrives in 0.8.
